# Ginails Pro

SaaS de gestion para profesionales de la estetica. En produccion, con suscriptoras pagas.

**En vivo:** https://ginailspro-app.gis-eesp91.workers.dev

## Que es

Ginails Pro resuelve la gestion diaria de un estudio de estetica: clientas, fichas, turnos y cobros. Nacio de una necesidad propia (administro mi propio estudio) y hoy lo usan otras profesionales del rubro con suscripcion paga.

## Funcionalidades

- Gestion de clientas con fichas, historial de servicios y notas
- Agenda con vistas de dia, semana y mes, y panel del dia en la pantalla de inicio
- Cobros por suscripcion integrados con MercadoPago via webhooks
- Modo oscuro completo
- PWA instalable, con service worker y diseno mobile-first
- Sistema de iconos SVG propio (70 iconos) y tokens de diseno unificados

## Stack

- **Frontend:** JavaScript, HTML5, CSS3, PWA con service worker
- **Backend:** Cloudflare Workers
- **Base de datos:** Firebase / Firestore
- **Auth:** Firebase Authentication
- **Pagos:** MercadoPago (webhooks)
- **Deploy:** Cloudflare

## Sobre el desarrollo

Trabajo el ciclo completo del producto: hablo con las usuarias, defino que construir, desarrollo, despliego y doy soporte. Uso mi propio estudio como entorno real de prueba, lo que me permite validar cada funcionalidad con uso real antes de liberarla.
